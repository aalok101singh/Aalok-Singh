Built with: Vite, React, TypeScript, Tailwind CSS, Lucide icons, Fontsource fonts (OFL), and one Vercel serverless function (`/api/weather.ts` — weather proxy/cache only, contains no core logic). Data: road network © OpenStreetMap contributors (ODbL) — Baran district extraction, bundled statically; village toponyms from OSM. Weather: Open-Meteo (CC BY 4.0), keyless, graceful synthetic fallback. AI coding assistant used for implementation velocity, as explicitly permitted by organizers. **Core statement:** *All routing, optimization, resource-allocation, triage, and decision logic in `src/engine/` is original work implemented from scratch in TypeScript — no algorithm libraries, no copied routing projects.*
